# Guía de Observación de Campo — Servicio Médico UADY

## 1. Información General del Instrumento

| Campo                    | Detalle                                                    |
|--------------------------|------------------------------------------------------------|
| **Instrumento**          | Guía de Observación de Campo Estructurada                  |
| **Objetivo**             | Observar y documentar cómo los derechohabientes del Servicio Médico UADY interactúan actualmente con la ventanilla de atención, con el fin de identificar puntos de dolor, patrones de comportamiento y factores contextuales que orienten el diseño de la aplicación móvil. |
| **Método**               | Observación directa no participante                        |
| **Lugar**                | Servicio Médico UADY — ventanilla principal de atención    |
| **Usuarios objetivo**    | Trabajadores (personal de intendencia, académicos y administrativos) que acuden presencialmente a la ventanilla |
| **Duración estimada**    | 60–90 minutos por sesión de observación                    |
| **Número de sesiones**   | Mínimo 2 (una en turno matutino, una en turno vespertino)  |
|

---

## 2. Consideraciones Éticas

- Esta observación se enfoca en **patrones generales de comportamiento** en un área de servicio público; no se registran datos personales.
- Los participantes que posteriormente sean abordados para una conversación informal deben otorgar su **consentimiento verbal informado**.
- No se tomarán fotografías ni grabaciones de video de personas identificables sin su consentimiento explícito.
- Los datos recopilados se utilizan exclusivamente con fines académicos dentro del curso de Interacción Humano-Computadora (IHC) en la Facultad de Matemáticas de la UADY.

## 4. Dimensiones de Observación

### 4.1 Llegada y Comportamiento en Fila

| # | Elemento a Observar | Registro |
|---|----------------------|----------|
| 1 | ¿Cómo llega el usuario al área de servicio? (caminando desde un edificio cercano, cruzando el campus, durante su descanso, etc.) | |
| 2 | ¿El usuario parece saber a dónde dirigirse, o pregunta por indicaciones? | |
| 3 | ¿Existe una fila visible o un sistema de turnos? Describir. | |
| 4 | ¿Cuánto tiempo espera el usuario antes de ser atendido? (estimación en minutos) | |
| 5 | ¿Qué hace el usuario mientras espera? (usa el teléfono, platica, lee, permanece de pie sin actividad) | |
| 6 | ¿El usuario parece tener prisa o está relajado? ¿Hay señales de presión de tiempo? | |

---

### 4.2 Interacción en la Ventanilla

| # | Elemento a Observar | Registro |
|---|----------------------|----------|
| 7 | ¿Qué trámite parece solicitar el usuario? (cita, pase médico, información, expediente, etc.) | |
| 8 | ¿El usuario trae documentos físicos? ¿Cuáles? (credencial, pase anterior, formato impreso, etc.) | |
| 9 | ¿El personal solicita información que el usuario no tiene disponible en ese momento? | |
| 10 | ¿Cuántos intercambios de ida y vuelta ocurren antes de completar el trámite? | |
| 11 | ¿El usuario parece comprender las indicaciones del personal? | |
| 12 | ¿Se observan momentos de confusión, duda o frustración? Describir. | |
| 13 | ¿El personal escribe, imprime o entrega algún documento al usuario? | |
| 14 | Tiempo aproximado de la interacción completa (en minutos). | |

---

### 4.3 Uso de Tecnología y Dispositivos

| # | Elemento a Observar | Registro |
|---|----------------------|----------|
| 15 | ¿El usuario porta un teléfono inteligente? ¿Es visible durante la visita? | |
| 16 | ¿El usuario consulta su teléfono en algún momento del proceso? (revisando mensajes, buscando información, etc.) | |
| 17 | ¿El personal le pide al usuario revisar su correo electrónico, una plataforma o un sistema digital? | |
| 18 | Si se requiere un paso digital, ¿el usuario lo realiza de forma independiente o necesita ayuda? | |
| 19 | ¿Hay computadoras o dispositivos digitales disponibles para autoservicio del usuario en el área? | |

---

### 4.4 Patrones de Comunicación y Asistencia

| # | Elemento a Observar | Registro |
|---|----------------------|----------|
| 20 | ¿El usuario llega solo o acompañado? Si viene acompañado, ¿el acompañante le ayuda? | |
| 21 | ¿El usuario pide ayuda o información a otras personas en la fila? | |
| 22 | ¿El usuario pide al personal que repita o aclare información? | |
| 23 | ¿Cuál es el tono de la interacción? (formal, amigable, tenso, apresurado) | |
| 24 | ¿El usuario parece realizar este trámite por primera vez o es algo habitual para él? | |

---

### 4.5 Salida y Resultado

| # | Elemento a Observar | Registro |
|---|----------------------|----------|
| 25 | ¿El usuario se retira con el trámite completado, o necesita regresar en otra ocasión? | |
| 26 | Si no se resolvió, ¿cuál parece ser la razón? (documento faltante, problema del sistema, requiere otro paso, etc.) | |
| 27 | ¿El usuario expresa satisfacción o frustración al retirarse? (señales verbales o no verbales) | |
| 28 | Tiempo total del usuario en el área de servicio (desde su llegada hasta su salida). | |
