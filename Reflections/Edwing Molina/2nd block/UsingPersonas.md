# Using Personas

Throughout the HCI course, we were introduced to the "Personas" method for user-centered design. I believe this method is quite effective when it comes to creating a profile of our target users, allowing us to design apps that truly serve them. This technique, which dates back to the 1990s, is particularly valuable when creating prototypes or even the final UI of an app, as long as the design is focused on the target users and ensures system quality.

<mark>In our project, we used the Persona technique to identify the usability quality attributes that we believe our system should possess to be usable for our target audience and to avoid excluding anyone due to excessive difficulty.</mark>

And in the future, we will use this same technique so that once we have the results of the usability tests, we can create a user-centered design proposal. With the help of the synthetic personas we generate, we can guide and create the UI, where the previously defined attributes will be reflected.

Currently, we haven't used it to generate UI designs, but as I mentioned, it's a very good technique for user-centered design, since it helps us better understand our users and think of solutions, not in terms of system functionality, but in terms of how easy the system is for them to use. We want to avoid a system that doesn't work for them due to poor UI design. Often, systems are created that are very helpful in many tasks, but the graphical interface is very confusing, which, instead of speeding up work, slows it down, leading to the system being discarded and considered a very bad investment for companies.
