# Usability vs UX

## Claim

It is true that usability and user experience are related to human-computer interaction, but they are different because usability focuses on functional performance, while user experience is based on user performance and how the user feels when interacting.

## Data

According with an article called "Cognitive Integration of Delays: Anticipated System Delays Slow Down User Actions" says that the systems delays or long breaks interrupt the user flow and increment they frustration, even the ISO establishes that "Usability refers to capability of a software product to be understood and attractive under specific conditions".

## Warrant

These concepts are common related and even confused because one important thing guide these concepts and is human psychology, always told us that are two different concepts that is true, but usually we don't stop to think that a system design focused on the user, is naturally more efficient and satisfying to use.

## Backing

And we can see this in how different recognized enterprises validate again Nielsen’s heuristics, because is a trivial concept that we could lose by time, but we can see the importance of how these frameworks are essential for intuitive interfaces.

## Qualifier

But we don't even forget that a product could be functional and useful, and gave a really bad user experience if we don't abord the more common problematics presented in these days as accessibility or etic design.

## Rebuttal

To embrace better this question i read an article called "Functionalism" of the Stanford Encyclopedia of Philosophy, and they talk about how some critics could be say that if a system is perfectly fuctional so use experience is secondary, but when we ignore the principles, users could still experiment confusion, bugs, even if a perfect program functionality is.

## Example

In our medical services app, we see a great difference in the appointment section:

Usability: Can the user cancel an appointment without errors and in a short period of time?

UX Feature: A "confirmation message" that uses a common and confortable language for every user.

Context: Before our project only they only had a confirmation by a call. Including a modal provides the UX attribute of User Satisfaction, which can be measured by the "System Usability Scale" (SUS) during testing.
