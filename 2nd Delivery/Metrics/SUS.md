# SUS (System Usability Scale) Questionnaire

This questionnaire should be completed by the user immediately after interacting with the system. It uses a 5-point Likert scale.

## 1. Questions

1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.

## 3. Scoring Methodology

To calculate the final score (0 to 100), process the values of each response ($x$) as follows:

1. **Odd Items (1, 3, 5, 7, 9):** Score = $x - 1$.
2. **Even Items (2, 4, 6, 8, 10):** Score = $5 - x$.
3. **Total:** Sum the 10 results and multiply by **2.5**.

> **Formula:** $Score = (\sum(P_{odd} - 1) + \sum(5 - P_{even})) \times 2.5$

---

## 4. Interpretation of Results

| SUS Score | Grade | Adjective / User Type |
|:---:|:---:|:---|
| **> 80.3** | A | Excellent / Promoters |
| **68 - 80.2** | B | Good / Acceptable |
| **51 - 67.9** | C / D | Poor / Marginal |
| **< 51** | F | Inacceptable |

**Note:** The industry average is **68**. Any score below this value indicates that usability improvements should be prioritized.
